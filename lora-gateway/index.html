Was sind LoRa-Gateways?

4 Min. Lesezeit

In diesem Artikel
  1. Wie funktionieren Gateways?
  2. Praxisfall: Wie kann ich LoRa-Gateways sinnvoll einsetzen?
  3. Worauf sollte ich bei einem LoRa-Gateway achten?
  4. Kann man ein LoRa-Gateway ohne Lizenz installieren?

LoRa-Gateways sind die Funkbrücke zwischen LoRaWAN-Endgeräten und einem Netzwerkserver. Sie empfangen die Funkpakete beispielsweise von Sensoren und leiten sie über Ethernet, WLAN oder Mobilfunk weiter. Für Nachrichten an ein Endgerät können sie auch senden. Ein Gateway übernimmt damit eine andere Aufgabe als der Sensor selbst oder die Anwendung, die später Messwerte auswertet.

Um zu verstehen, was sich hinter dem Begriff des LoRa-Gateways versteckt, ist es sinnvoll, das Wortpaar vorerst aufzutrennen.

LoRa steht für Long Range und bezeichnet die Funktechnik für kleine Datenmengen bei geringem Energiebedarf. LoRaWAN beschreibt das darüber organisierte Netzwerk. Wenn im Alltag von einem LoRa-Gateway oder LoRa-Router gesprochen wird, ist meist ein Gateway für dieses LoRaWAN-Netz gemeint. Ein einzelnes LoRa-Funkmodul ist damit nicht automatisch gleichzusetzen.

LoRa-Gateways dienen als Brücke zwischen elektronischen Geräten, auch Nodes oder Endknoten genannt, und den nachgelagerten IoT-Diensten. So können die Messwerte eines Sensors an eine Cloud-Anwendung oder ein lokal betriebenes System gelangen. Das ist besonders bei nachgerüsteten oder weit verteilten Messstellen interessant, an denen sich eine Datenleitung nicht sinnvoll verlegen lässt.

Wie funktionieren Gateways?

Ein typisches LoRaWAN-Gateway enthält einen LoRa-Konzentrator. Er kann mehrere Funkkanäle und unterschiedliche Übertragungsparameter verarbeiten. Dabei erfolgt bereits im Gateway die Demodulation: Aus dem empfangenen Funksignal werden Datenpakete gewonnen. Die Gateway-Software leitet diese Pakete anschließend an den Netzwerkserver weiter. Bei der Softwareausstattung lassen sich unter anderem folgende Varianten unterscheiden:

Einerseits Gateways, die über eine Minimal-Firmware betrieben werden. Diese sind kostengünstig und einfach zu bedienen und laufen nur mit einer Software zur Weiterleitung der Pakete.

Außerdem können LoRa-Gateways verwendet werden, die mit einem Betriebssystem arbeiten, bei dem die Paketweiterleitungs-Software im Hintergrund läuft. Auf diese Weise hat der Gateway-Administrator mehr Spielraum bei der Verwaltung seines Gateways.

Die Datenrate zwischen Endgerät und Gateway ist vergleichsweise gering. Kurze Übertragungen und Ruhezeiten können den Energieverbrauch des Endgeräts niedrig halten. Eine bestimmte Reichweite oder Batterielaufzeit ist dadurch aber nicht garantiert. Das Gateway selbst bleibt normalerweise empfangsbereit und benötigt meist eine dauerhafte Stromversorgung.

Ein Endgerät ist im üblichen LoRaWAN-Betrieb nicht fest mit einem bestimmten Gateway gekoppelt. Mehrere passend konfigurierte Gateways können dasselbe Paket empfangen. Der Netzwerkserver erkennt solche Mehrfachempfänge, entfernt Duplikate und bearbeitet die Nachricht weiter. Bei einem Downlink entscheidet das Netzwerk, welches geeignete Gateway die Nachricht zum Endgerät überträgt. Die Architekturdokumentation von The Things Network beschreibt diese Aufgabenteilung.

Die IP-Verbindung des Gateways zum Server wird auch Backhaul genannt. Sie kann etwa über Ethernet, WLAN oder einen Mobilfunkrouter laufen. Die Messwertdarstellung entsteht erst in der Anwendung. Auch ein Gateway mit guter Funkabdeckung benötigt deshalb eine funktionierende Serveranbindung und passende Datenverarbeitung.

Praxisfall: Wie kann ich LoRa-Gateways sinnvoll einsetzen?

Mögliche Anwendungsgebiete für LoRaWAN-Netzwerke gibt es viele. Sehr beliebt ist die Überwachung bestimmter Umgebungszustände. Angenommen, Sie benötigen regelmäßig Informationen über Temperatur, Luftfeuchtigkeit oder den Türstatus Ihrer Kühlhäuser. Dafür können passende Endgeräte ihre Messwerte über ein Gateway zur zentralen Anwendung senden.

Vorab ist es sinnvoll, festzulegen, welche Raumeigenschaften Sie im Auge behalten wollen. Danach wählen Sie die Sensoren und ihre Montageorte. Gerade Kühlhäuser können den Funk durch Metallwände und geschlossene Türen stark abschirmen. Ob ein einziges Gateway ausreicht oder mehrere Standorte nötig sind, sollte deshalb vor Ort gemessen werden.

Das Gateway wird mit dem Netzwerkserver verbunden, beispielsweise über LAN oder LTE. Endgeräte müssen im vorgesehenen LoRaWAN-Netz eingerichtet sein; ein bloßes Einschalten reicht nicht. Nach der Datenanbindung kann die Anwendung Verläufe anzeigen und bei Abweichungen eine Meldung auslösen. Bei einem längeren Ausbleiben von Messwerten sollte sie ebenfalls reagieren, damit fehlende Daten nicht als unauffälliger Zustand erscheinen.

So lässt sich eine Kühlraumüberwachung nachrüsten, ohne jeden Sensor mit einer Netzwerkleitung zu verbinden. Die Betriebskosten umfassen dennoch mehr als die Sensorbatterie: Gateway-Strom, Internetzugang, Plattform, Wartung und gegebenenfalls Mobilfunktarife gehören in die Kalkulation. Weitere Planungsschritte erläutert der Ratgeber zum LoRaWAN-Monitoring.

Kann man ein LoRa-Gateway ohne Lizenz installieren?

LoRaWAN verwendet häufig Frequenzbereiche, für die keine individuelle Frequenzlizenz erforderlich ist. „Lizenzfrei“ bedeutet aber nicht „ohne Regeln“. Zulässige Frequenzen, Sendeleistung und Funkbelegung richten sich nach dem Land und dem Frequenzbereich. Die regionalen LoRaWAN-Parameter sind ein technischer Ausgangspunkt; maßgeblich bleiben die örtlichen Vorgaben.

Ein zusätzliches Gateway kann die Abdeckung eines Netzes verbessern. Es wird jedoch nicht allein durch seine Installation Teil eines weltweiten Gemeinschaftsnetzes. Dafür muss es entsprechend angebunden und freigegeben sein. Ebenso können Unternehmen eigene Netze betreiben. Welche Betriebsmodelle infrage kommen, zeigt der Überblick über LoRaWAN-Anbieter.
